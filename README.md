# STETS Home

STETS Home — учебный дипломный проект мобильного приложения для управления устройствами умного дома.

Цель проекта — спроектировать первую версию приложения STETS Home, позволяющего пользователю управлять умными устройствами и использовать фирменный режим энергосбережения.

## Основной функционал

В рамках проекта были проработаны следующие возможности:

- регистрация и авторизация пользователя;
- восстановление доступа к аккаунту;
- управление комнатами;
- подключение устройств;
- управление состоянием устройств;
- включение режима энергосбережения;
- создание и управление сценариями;
- запуск сценариев по расписанию;
- управление доступом пользователей к дому.

Функциональность первой версии отражена в User Story Map и далее проверяется в ПМИ.

## Ключевая особенность продукта

Одной из основных особенностей STETS Home является возможность включать и отключать режим энергосбережения для умного устройства.

Эта функция отражена как в проектировании интерфейса, так и в сценариях проверки приложения.

## Прототип

В прототипе представлены основные пользовательские сценарии:

- вход в приложение;
- работа с домом и комнатами;
- просмотр и управление устройствами;
- управление режимом энергосбережения;
- работа со сценариями автоматизации;
- управление доступом к дому.
